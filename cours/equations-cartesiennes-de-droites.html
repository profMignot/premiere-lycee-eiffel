1De l’équation réduite à l’équation cartésienne

Rappel (classe de seconde)

Dans un repère, une droite d possède une équation réduite :

  • si elle n’est pas verticale : y = mx + p (m est le coefficient directeur, p l’ordonnée à l’origine) ;
  • si elle est verticale : x = k.
Définition

Toute droite du plan admet une équation de la forme

ax + by + c = 0

où a, b et c sont trois réels, avec a et b non tous les deux nuls. C’est une équation cartésienne de la droite.

Méthode

Pour passer d’une équation réduite à une équation cartésienne, on passe tous les termes dans le même membre, de façon que l’autre membre soit égal à 0. S’il y a des fractions, on multiplie d’abord par le dénominateur.

Exemple

La droite d a pour équation réduite y = 2x + 3.

y = 2x + 3
⇔ 0 = 2x − y + 3
⇔ 2x − y + 3 = 0

Donc 2x − y + 3 = 0 est une équation cartésienne de d : ici a = 2, b = −1 et c = 3.

Remarques
  • L’équation cartésienne n’est pas unique. En multipliant par un réel non nul, on obtient une autre équation de la même droite : 4x − 2y + 6 = 0 décrit la même droite que 2x − y + 3 = 0.
  • On simplifie toujours l’équation. Si a, b et c ont un diviseur commun, on divise par ce nombre. Par exemple, on simplifie en divisant par 2 :
    4x − 2y + 6 = 0
    ⇔ 2x − y + 3 = 0
  • Droite verticale x = 4 : elle s’écrit x − 4 = 0, avec a = 1, b = 0, c = −4.
  • Droite horizontale y = 3 : elle s’écrit y − 3 = 0, avec a = 0, b = 1, c = −3.

2Vecteur directeur d’une droite

Définition

Soit d une droite. Un vecteur directeur de d est un vecteur non nul u qui a la même direction que d : on peut le représenter par une flèche « posée » sur d.

Rappel

Les coordonnées (x ; y) d’un vecteur indiquent un déplacement : x unités horizontalement (vers la droite si x > 0, vers la gauche sinon) puis y unités verticalement (vers le haut si y > 0, vers le bas sinon).

Construire un vecteur directeur

Problème : on donne une droite d et on veut construire un vecteur directeur de d, c’est-à-dire une flèche qui a la même direction que d.
Méthode : 1) on place un point A sur d ; 2) à partir de A, on se déplace le long de la droite en comptant les unités : horizontalement, puis verticalement ; 3) on trace la flèche. Clique sur « Suivant » pour voir la construction.

À retenir (1)

Si u est un vecteur directeur de d, alors tout vecteur ku (avec k ≠ 0) en est un aussi : une droite a une infinité de vecteurs directeurs, tous colinéaires (multiples les uns des autres).

Exemple. Choisis une valeur de k : le vecteur ku (en orange) s’allonge, se raccourcit ou se retourne, mais il garde la direction de d.

À retenir (2)

Une droite est entièrement déterminée par un point et un vecteur directeur.

Exemple. La droite d passe par A(1 ; −1) et a pour vecteur directeur u(2 ; 1).

3Coordonnées d’un vecteur défini par deux points

Propriété

Dans un repère, si A(xA ; yA) et B(xB ; yB), alors le vecteur AB a pour coordonnées

AB ( xB − xA ; yB − yA )

Moyen mnémotechnique : arrivée − départ, pour chaque coordonnée.

Exemple rédigé ligne par ligne

On donne A(2 ; −3) et B(5 ; 1). Calculons les coordonnées de AB.

AB ( xB − xA ; yB − yA )
AB ( 5 − 2 ; 1 − (−3) )
AB ( 3 ; 4 )

Pour aller de A à B : 3 unités vers la droite, puis 4 vers le haut.

4Vecteur directeur à partir d’une équation cartésienne

Propriété

Si une droite d a pour équation cartésienne ax + by + c = 0, alors le vecteur

v ( −b ; a )

est un vecteur directeur de d.

Exemple

La droite d a pour équation 3x − 2y + 5 = 0. Ici a = 3 et b = −2, donc

v ( −b ; a )
v ( −(−2) ; 3 )
v ( 2 ; 3 )

Le vecteur v(2 ; 3) a bien la direction de la droite : 2 unités à droite, 3 vers le haut.

Cas particuliers
  • Équation réduite y = mx + p : elle s’écrit mx − y + p = 0, donc v(1 ; m) est directeur.
  • Droite verticale x − 4 = 0 : a = 1, b = 0, donc v(0 ; 1).

5Tracer une droite à partir de son équation cartésienne

On connaît une équation cartésienne ax + by + c = 0 d’une droite d et on veut tracer d dans un repère. Deux méthodes sont possibles.

Méthode 1 : deux points (tableau de valeurs)
  1. On choisit deux valeurs de x.
  2. Pour chacune, on remplace x dans l’équation et on résout pour trouver y.
  3. On place les deux points obtenus et on trace la droite qui passe par ces deux points.

Conseil : choisir des valeurs de x qui donnent des y entiers, et des points assez éloignés l’un de l’autre pour que le tracé soit précis.

Exemple

Tracer la droite d d’équation 2x + 3y − 7 = 0.

Pour x = −1 :

2 × (−1) + 3y − 7 = 0
⇔ 3y = 9
⇔ y = 3

Pour x = 2 :

2 × 2 + 3y − 7 = 0
⇔ 3y = 3
⇔ y = 1

On regroupe les résultats dans un tableau de valeurs :

x−12
y31

Donc les points A(−1 ; 3) et B(2 ; 1) appartiennent à d : on les place et on trace la droite (AB).

Ici, x = 0 donnerait y = 73 : ce point serait difficile à placer avec précision.

Méthode 2 : un point et un vecteur directeur
  1. On cherche un point A de d : on choisit une valeur de x et on calcule y (comme dans la méthode 1).
  2. On écrit le vecteur directeur v(−b ; a) (propriété de l’étape 4).
  3. À partir de A, on trace v en comptant les unités, puis la droite qui passe par A et a la direction de v.

Exemple

On reprend la droite d d’équation 2x + 3y − 7 = 0.

Un point. Pour x = −1, on a trouvé y = 3 : le point A(−1 ; 3) appartient à d.

Un vecteur directeur. Ici a = 2 et b = 3, donc

v ( −b ; a )
v ( −3 ; 2 )

À partir de A, on se déplace de 3 unités vers la gauche puis de 2 unités vers le haut : on arrive au point C(−4 ; 5), qui est aussi sur d. On trace la droite.

On retrouve bien la même droite qu’avec la méthode 1.

Remarque

Si b = 0, l’équation s’écrit ax + c = 0 : on ne peut pas choisir x librement. La droite est verticale. Par exemple, 2x − 6 = 0 équivaut à x = 3 : c’est la droite verticale qui passe par le point (3 ; 0).

6Méthode : trouver une équation cartésienne

Méthode

On connaît un vecteur directeur u(α ; β) de d et un point A de d.

  1. Avec la propriété de l’étape 4, v(−b ; a) est directeur : on en déduit facilement a et b. On écrit ax + by + c = 0, avec c encore inconnu.
  2. Le point A appartient à d : ses coordonnées vérifient l’équation. On les remplace dans ax + by + c = 0 et on résout pour trouver c.
  3. Si a, b et c ont un diviseur commun, on simplifie l’équation en divisant par ce nombre.

Si l’énoncé donne deux points A et B, on commence par calculer AB (étape 3), qui sert de vecteur directeur.

Exemple pas à pas

Trouver une équation cartésienne de la droite d qui passe par A(2 ; −1) et dont un vecteur directeur est u(3 ; 4).

Étape 1. On cherche a et b : v(−b ; a) doit être égal (ou colinéaire) à u(3 ; 4). On prend −b = 3 et a = 4, donc a = 4 et b = −3.
Étape 2. L’équation est de la forme 4x − 3y + c = 0.
Étape 3. Le point A appartient à la droite d, donc ses coordonnées vérifient l’équation de la droite :
4 × 2 − 3 × (−1) + c = 0
8 + 3 + c = 0
c = −11
Étape 4. Une équation cartésienne de d est 4x − 3y − 11 = 0.
Vérification. Le point B(5 ; 3) (obtenu en ajoutant u à A) doit aussi être sur d : 4 × 5 − 3 × 3 − 11 = 20 − 9 − 11 = 0 ✔.
