1
Développer et réduire (3x − 2)2 − (x + 1)(x − 1).
Voir la réponse

On utilise (a − b)2 = a2 − 2ab + b2 et (a + b)(a − b) = a2 − b2 :

(3x − 2)2 − (x + 1)(x − 1) = 9x2 − 12x + 4 − (x2 − 1)
= 9x2 − 12x + 4 − x2 + 1
= 8x2 − 12x + 5
2
Factoriser 9x2 − 25 puis x2 + 10x + 25.
Voir la réponse

On reconnaît a2 − b2 = (a − b)(a + b) avec a = 3x et b = 5 :

9x2 − 25= (3x)2 − 52
9x2 − 25= (3x − 5)(3x + 5)

On reconnaît a2 + 2ab + b2 = (a + b)2 avec a = x et b = 5 :

x2 + 10x + 25= x2 + 2 × x × 5 + 52
x2 + 10x + 25= (x + 5)2
3
Factoriser (x + 2)(3x − 1) + (x + 2)(x + 5).
Voir la réponse

Les deux termes ont le facteur commun x + 2 :

(x + 2)(3x − 1) + (x + 2)(x + 5) = (x + 2)[(3x − 1) + (x + 5)]
= (x + 2)(4x + 4)
= 4(x + 1)(x + 2)
4
Résoudre dans ℝ : (2x + 1)(x − 5) = 0.
Voir la réponse

Un produit de facteurs est nul si, et seulement si, l’un au moins des facteurs est nul :

⇔(2x + 1)(x − 5) = 0
⇔2x + 1 = 0oux − 5 = 0
⇔2x = −1oux = 5
⇔x = −12oux = 5

Donc S = {−12 ; 5}.

5
Résoudre dans ℝ : (x − 3)2 = 4.
Voir la réponse

Un nombre dont le carré vaut 4 est égal à 2 ou à −2 :

⇔(x − 3)2 = 4
⇔x − 3 = 2oux − 3 = −2
⇔x = 5oux = 1

Donc S = {1 ; 5}.

6
Résoudre dans ℝ : x2 = 7.
Voir la réponse

Comme 7 > 0, l’équation a deux solutions opposées :

⇔x2 = 7
⇔x = √7oux = −√7

Donc S = {−√7 ; √7}.

7
Résoudre dans ℝ : 5x = 23.
Voir la réponse

Le dénominateur x est non nul. On fait les produits en croix :

⇔5x = 23
⇔5 × 3 = 2x
⇔15 = 2x
⇔x = 152

Donc S = {152}.

8
Résoudre dans ℝ : 3(x − 2) > 5x + 4.
Voir la réponse

On développe, on regroupe les x puis on divise par −2 : le sens de l’inégalité change.

⇔3(x − 2) > 5x + 4
⇔3x − 6 > 5x + 4
⇔−2x > 10
⇔x < −5

Donc S = ]−∞ ; −5[.

9
Isoler h dans V = 13πr2h.
Voir la réponse

On multiplie par 3 puis on divise par πr2 (non nul) :

⇔V = 13πr2h
⇔3V = πr2h
⇔h = 3Vπr2
10
Calculer R sachant que 1R = 120 + 130.
Voir la réponse

On additionne les fractions avec le dénominateur commun 60 :

1R= 120 + 130
1R= 360 + 260
1R= 560
1R= 112

Deux nombres non nuls ayant le même inverse sont égaux, donc R = 12.
