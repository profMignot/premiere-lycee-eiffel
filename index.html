Comment ajouter une activité ?

Cette page se met à jour toute seule. Pour publier une nouvelle remédiation :

  1. Sur le dépôt GitHub, clique sur Ajouter un fichier → Téléverser des fichiers.
  2. Dépose le fichier .html de l'activité, de préférence dans le dossier du thème (crée le dossier en tapant son nom avant le fichier, ex. signes/mon-activite.html).
  3. Valide (Commit). L'activité apparaît ici automatiquement, dans la bonne rubrique.

Dossiers reconnus :

signes/developpement/factorisation/racines/forme-canonique/

Sans dossier, le thème est deviné d'après le nom du fichier (un nom contenant « signe », « factoris », « develop »…). Sinon l'activité va dans « Autres ».
