Comment ajouter une ressource ?

Cette page se met à jour toute seule. Pour publier un cours, un exercice ou une remédiation :

  1. Sur le dépôt GitHub, clique sur Add file → Upload files.
  2. Range le fichier .html dans un dossier type / chapitre (tape le chemin devant le nom), par exemple cours/signes/mon-cours.html ou exercices/racines/serie-1.html.
  3. Valide (Commit changes). La ressource apparaît ici automatiquement, avec son étiquette et dans le bon chapitre.

Dossiers de type :

cours/exercices/remediations/

Dossiers de chapitre :

signes/developpement/factorisation/racines/forme-canonique/

À défaut de dossier, le type et le chapitre sont devinés d'après le nom du fichier (par ex. « cours », « exo », « signe », « factoris »…). Ce qui n'est pas reconnu va dans « Autres ».
